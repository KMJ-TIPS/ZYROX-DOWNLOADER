ZYROX DOWNLOADER v1.0.0

Ye Saurabh-gzp/VidGrab ka rebranded Android app hai.

PHONE: Android 10 ya newer, ARM64 (arm64-v8a).
INSTALL: APK phone par download karke open karein. Agar Android pooche, apne browser/file manager ke liye "Install unknown apps / Allow from this source" enable karein.
USE: Video ka public link copy karein, app me Paste > Find media > quality select > Save video/Save audio. Kisi social app ke Share menu se bhi ZYROX ko link bhej sakte hain.
LIBRARY: Progress, cancel/retry, history, play, share aur delete.
MUSIC: Downloaded audio tracks ka local player. Playback app ke player se bahar jaane par pause hota hai.
THEME: Settings me System/Light/Dark.
ENGINE: yt-dlp/Python aur FFmpeg phone par bundled hain; developer server/API key ki zarurat nahi.
FILES: Movies/ZYROX/Video aur Music/ZYROX/Audio.

Naya logo, launch icon, Java animated splash, mint/ink UI aur light theme included hain. Base project Kotlin/Jetpack Compose hai; splash aur local player Java me hain.

Platform support yt-dlp aur website access rules par depend karta hai. Private/login-only/DRM content guaranteed nahi hai. Account cookies import feature included nahi hai.

App alag package com.zyrox.downloader me install hota hai. Ye local development signing identity se signed release build hai. Source ZIP me keystores/passwords/local SDK paths included nahi hain. Apni distribution key configure karne ke steps source README/docs me hain.

Validation: 73 JVM tests pass; Android lint pass; APK signature/ZIP alignment pass; real host sample download pass. Phone/emulator par app runtime verification abhi pending hai. Detailed results source ke docs/VALIDATION-ZYROX.md me hain.
